# Sounds

`done.mp3` and `request.mp3` are Herdr's attention sounds, from [herdr-app](https://github.com/herdrdev/herdr-app) (`assets/sounds/`), unchanged. They are under the Apache License 2.0, a copy of which is in `LICENSE` beside them.

Spaces plays `request.mp3` when an agent starts waiting for you and `done.mp3` when one finishes while you aren't looking (`src/sound.rs`).
